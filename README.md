# PolyBrowser (Still in early development 😭)

## PolyBrowser is a lightweight, privacy-focused Chromium browser

### Features:
- **Zero Google Telemetry**:
  - Google Metrics Service & UKM disabled.
  - Crashpad / Crash reporting uploads to Google disabled.
  - Google Accounts, Gaia, and Chrome Sync defaults disabled.
  - RLZ tracking pings and Domain Reliability telemetry discarded.
  - Google Omaha update checks disabled.
  - SafeBrowsing telemetry pingbacks disabled.
- **Built-in / Auto-install uBlock Origin**:
  - Automatically installed on first launch via component loader, preinstalled extensions, and external extension configuration (`cjpalhdlnbpafiamejdnhcphjbkeiagm`).
- **Windows Mica & Frosted Glass Design**:
  - Windows 11 Mica Alt (`DWMSBT_TABBEDWINDOW`) system backdrop applied to top-level browser frames.
  - Glass frame enabled with frosted translucent tab strip and tabs.
  - New Tab Page styled with translucent acrylic / Mica glassmorphic cards and search box (`backdrop-filter: blur(24px) saturate(180%)`).
